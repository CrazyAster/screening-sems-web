Screening SEMS Local

Reportes geográficos por correo electrónico.

Screening SEMS Local es una aplicación de escritorio que usa QGIS para generar un reporte de análisis alrededor de una ubicación. Se ejecuta en la computadora del operador.

Cómo funciona

Un remitente autorizado envía el nombre del proyecto, las coordenadas y el radio de análisis. La aplicación usa la API de Gmail para consultar el buzón autorizado, leer la solicitud y responder con el PDF y las observaciones. El operador recibe una copia cuando el solicitante es otra persona.
